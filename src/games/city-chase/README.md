# シティチェイス（CITY CHASE）

ボードゲーム「シティチェイス」（Martino Chiacchiera & Gabriele Mari / Korea Boardgames、日本語版: カワダ）のルールを再現した3Dデジタル版。
夜の街に並ぶ25棟のビルのどこかに隠れた犯人の車を、警察チームがヘリコプター3機で捜索する「鬼ごっこ × かくれんぼ」。

## 概要

- 犯人 vs 警察チームの非対称推理ゲーム。最大11ラウンド
- 警察は11ラウンド以内に犯人の車を見つけたら勝ち。犯人は逃げ切れば勝ち
- 1人用（AI対戦）と、1台を交代で使う「みんなで対戦」に対応

## モード

| モード | 内容 |
| --- | --- |
| 警察で遊ぶ | プレイヤーがヘリ3機を操作。AIが犯人 |
| 犯人で遊ぶ | プレイヤーが犯人の車を操作。AIが警察 |
| みんなで対戦 | 1台を交代で使う（犯人1人 vs 警察チーム）。交代画面で画面を渡す |

AIの強さ: やさしい / ふつう / むずかしい（タイトルで選択、保存される）

## 操作方法

### 共通
- ドラッグ（1本指）: 街を回転 / ピンチ・ホイール: ズーム
- `☰` メニュー: つづける・サウンド・光のエフェクト（ブルーム）・あそびかた・タイトルへ
- `🔍` 推理ヒント: 犯人がいそうなビルを色で表示（警察を人間が操作するフェーズのみ）

### 警察
1. 行動するヘリをタップ（HUDのヘリチップ、またはキー `1` `2` `3` でも選択可）
2. 青く光る交差点をタップ → 移動 / オレンジに光るビルをタップ → 捜索
3. 3機すべてが行動すると次のラウンドへ
- `Esc`: ヘリの選び直し

### 犯人
1. 赤く光るビルをタップ（1ラウンド目はどこでも、2ラウンド目以降はタテヨコ隣接）
2. 「ここに隠れる」で確定（`Enter` でも可、`Esc` で選び直し）

## ゲームルール（原作準拠）

### コンポーネント
- ビル 25棟（高10・低15）を 5×5 に配置。高さの配置は毎回ランダム
- 交差点 16か所（4×4）。各交差点は4つのビルに囲まれている
- ヘリコプター 3機（ピンク / イエロー / グリーン）。1交差点に1機まで。人数に関係なく3機すべて使う
- 車 1台（犯人）
- 痕跡コマ 11個: 黄1（1ラウンド目=スタート地点）/ 赤1（6ラウンド目）/ 青9（その他）
- ラウンドボード（11マス。上段 1→5、下段 11←6 の蛇行配置）

### 1ラウンドの流れ
1. **犯人フェーズ**（警察は目を閉じる）
   - 1ラウンド目: 好きなビルの下に車を隠し、黄色の痕跡コマを一緒に置く
   - 2ラウンド目以降: 前のビルから車を出し（痕跡は残す）、**タテヨコに隣接**し、**痕跡コマが置かれていない**ビルへ移動して、そのラウンドの痕跡コマと一緒に隠れる
   - 移動できるビルがなければ「包囲」を宣言 → 警察の勝ち
2. **警察フェーズ**: 各ヘリが「移動」か「捜索」を1回ずつ（順番は自由）
   - 移動: タテヨコ隣の交差点へ。ナナメ不可。他のヘリがいる交差点は不可
   - 捜索: 交差点を囲む4つのビルから1つを持ち上げる
     - 何もなし → 戻す
     - 痕跡コマ → ビルの上に置いて公開（色で「いつ通ったか」の手がかりになる）
     - 車 → 逮捕。警察の勝ち

### 勝敗
- 逮捕: 車を発見 → 警察の勝ち
- 逃走成功: 11ラウンド目の警察フェーズが終わっても見つからない → 犯人の勝ち
- 包囲: 犯人フェーズに移動できるビルがない → 警察の勝ち

### デジタル版での扱い
- 痕跡を発見済みのビル（車があり得ない）は捜索候補から外している
- 「警察は目を閉じる」は、AI犯人のときは暗転演出、みんなで対戦のときは交代画面で再現
- リザルトで犯人の逃走ルートを全公開できる

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | ページ構造（HUD / タイトル / 交代 / リザルト / メニュー / ルール） |
| `styles.css` | デザイントークン・HUD・オーバーレイ・レスポンシブ |
| `game.js` | 進行の指揮（モード・フェーズ遷移・UI更新・演出とAIの呼び出し） |
| `rules.js` | ルールエンジン（純ロジック。DOM/Three.js 非依存） |
| `belief.js` | 推理モデル（公開情報と矛盾しない犯人の全経路を列挙して確率化） |
| `ai.js` | 犯人AI・警察AI（難易度3段階） |
| `renderer.js` | Three.js による3D描画・演出（ビル・ヘリ・車・痕跡・パーティクル・ブルーム） |
| `audio.js` | WebAudio 合成の効果音とBGM |

開発用: `scripts/city-chase-sim.mjs` で AI 同士の対戦シミュレーション（勝率・整合性チェック）ができる。

```
node scripts/city-chase-sim.mjs 200 normal normal 1
```

## 状態 / データ

- `CityChaseGame`（`rules.js`）: `phase`（setup / thief / police / over）、`round`、`helis[]`（pos・acted）、`thief`（pos・path）、`traces[]`（round・color・found）、`searches[]`、`result`
- `publicView()` は警察が知り得る情報だけを返す（AI・ヒントはこれだけを使う）
- 永続化: 設定（サウンド / ブルーム / 難易度）のみ `localStorage`（`city-chase:settings`）。対局の保存はなし

## AI について

- 警察AI: 自己回避経路（最大約4.3万通り）の全列挙で「犯人が今いる確率」「痕跡が眠っている確率」を厳密に計算し、各ヘリの捜索/移動（先読みあり）の期待値で行動。1機ごとに結果を反映してから次を決める
- 犯人AI: 包囲されない経路の確保、ヘリに捜索されるリスク、ヘリからの距離、警察の推理上の目立ちにくさをスコア化。「むずかしい」は警察AIの行動をシミュレーションして回避

## 画面 / レスポンシブ

- PC / タブレット / スマホ（縦・横）対応。画面サイズに合わせてカメラが盤全体を自動フィット
- セーフエリア（ノッチ）に配慮。タップ領域は44px以上
- 重い端末ではブルームを自動オフ（メニューから手動切替も可）

## 素材 / クレジット

- 3Dモデル・テクスチャ・効果音はすべてプログラム生成（外部ファイルなし）
- フォント: Outfit / M PLUS Rounded 1c（Google Fonts）
- 原作: CITY CHASE（Korea Boardgames, 2021 / カワダ 日本語版 KBG-15, 2023）。本作はルールを再現したファンメイドのデジタル版で、原作の画像・ロゴ等は使用していない
