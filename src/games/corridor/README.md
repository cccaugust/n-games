# コリドール（Quoridor）

9×9の盤でコマを進め、反対側のゴール行に先に着いた人が勝ち。壁で相手の道をふさぐのが醍醐味の2人用アブストラクト。1台で向かい合って遊ぶ対面モードと、CPU対戦（3段階）に対応。

## 概要

- 自分のコマを反対側のゴール行（色つきの列）に運ぶレース
- 各プレイヤー 10枚（設定で6枚）の壁。毎ターン「1マス進む」か「壁を1枚置く」
- 壁は2マス分。重ね・交差は不可、相手のゴールへの道を完全にふさぐ置き方も不可
- 相手のコマと隣り合ったら飛び越え可。飛び越え先が壁なら斜めに回り込める

## 操作方法

### 共通（タップ / クリック）
- **進む**: 自分の番になると移動できるマスが自分の色で光る → タップで移動（「コマの移動も確認する」設定ONなら確認バーが出る）
- **壁を置く**: 操作バーの「🧱 かべ」→ 向き「━ よこ / ┃ たて」を選ぶ → 盤の置きたい場所をタップ → 半透明の壁（プレビュー）が出る → 「✓ ここに置く」で確定
  - 同じ場所をもう一度タップしても確定
  - 「🔄 回転」でプレビューの向きをその場で切替
  - 置けない場所は赤い ✕ と理由（重なる / 道がなくなる）を表示。確定ボタンは押せない
  - 壁モード中は、置ける交点が自分の色の点、道がなくなる交点が赤い点で表示される
- **もどす**: 「↩ もどす」で1手前に戻す（何手でも）。CPU戦では自分の番まで（CPUの手も一緒に）戻る

### 操作バーの位置
- 2人対戦＋対面モード: 上側プレイヤー用の操作バーは画面上部に180°回転して表示（タブレット向け）。縦画面で高さが足りない端末では下側のみ表示
- CPU対戦: 人間は常に下側（P1・青）、CPUは上側

### キーボード（PC）
- `↑↓←→`: その方向へ移動（飛び越え含む）
- `W`: 壁モード切替
- `R`: 壁の向きを回転
- `Enter` / `Space`: 確定
- `Esc`: やめる（プレビュー取消 / 壁モード解除）
- `Z` / `Backspace`: もどす

## ゲームルール

### 移動
- 1ターンに1マス、上下左右のいずれか
- 壁で塞がれた隙間は通れない
- 相手のコマの隣で、その向こうが空いていれば「飛び越え」
- 飛び越え先が壁/盤外なら、相手の左右へ「斜め移動」

### 壁
- 10枚 or 6枚（メニューで選択）
- 横置き / 縦置き、2マス分の長さ
- 既存の壁と重ならない / 交差しない
- 両プレイヤーともゴールへ到達できる経路が残ること

### 勝利
- 自分のコマがゴール行（P1=row 0 / P2=row 8）に到達した瞬間に勝ち
- リザルトに手数・使った壁・通算成績を表示

## CPU（3段階）

- **やさしい**: 基本は最短路を進む。ときどき壁、ときどき寄り道
- **ふつう**: 1手読み。評価 = 相手の残り歩数 − 自分の残り歩数 + 0.35×(壁の差)
- **つよい**: 2手読み（自分の手 → 相手の最善応手）。候補の壁は「相手の道のりを伸ばす」ものを効果順に上位のみ検討

自動対戦（12局ずつ）での目安: つよい＞ふつう＞やさしい の順で勝率が高く、1手の思考時間は最大でも 0.1 秒未満。

- `README.md`: このファイル

## 状態 / データ

- `state.board` (`Board`): `h`/`v` (Uint8Array 81) が壁の遮断、`anchor` (Uint8Array 64) が交点の使用状況、`walls[]`、`pawns[]`、`wallsLeft[]`、`turn`
- `state.history[]`: 各手の前の `Board` スナップショット（もどす用）
- `state.mode`: `'move'` | `'wall'`、`state.orient`: `'h'` | `'v'`
- `state.pending`: 確認待ちの手 `{ type:'wall', o, c, r, legal }` / `{ type:'move', c, r }`
- `state.cpu`: `null` | `{ pi: 1, level }`
- 永続化（localStorage）
  - `corridor.settings.v2`: モード / CPUレベル / 先手 / 壁の枚数 / 対面モード / 移動確認 / ミュート
  - `corridor.stats.v1`: 通算成績（2人対戦はP1/P2の勝数、CPU戦はレベル別の勝敗）

## 壁の座標系

`(o, c, r)`。c, r は 0〜7（盤内側の交点）。壁はその交点を中心に2マス分。

- **h (よこ) (c, r)**: cells (c,r)↔(c,r+1) と (c+1,r)↔(c+1,r+1) の縦方向移動を遮る
- **v (たて) (c, r)**: cells (c,r)↔(c+1,r) と (c,r+1)↔(c+1,r+1) の横方向移動を遮る

衝突: 同じ交点に別の壁（交差 / 同位置）、同じ向きで1マスずれ（重複）。

## 画面 / レスポンシブ

- 縦画面（タブレット）: 上サイド（180°回転）/ 盤 / 下サイド。盤はスクロール無しで収まるようJSでサイズ計算
- 縦画面で高さ 760px 以下: 上側は名前パネルのみ、操作バーは下側だけ
- 横画面（高さ 720px 以下、または幅 1000px 以上）: 盤を左、ヘッダー＋パネル＋操作を右の2カラム
- 幅 520px 以下・横画面: パネル/操作をコンパクト表示（ラベル省略、壁ピップ非表示）
- セーフエリア（`env(safe-area-inset-*)`）対応、`100svh` 基準
