# ブロックワールド（BLOCK WORLD）

マインクラフト風の 3D ボクセルサンドボックス。無限に広がる地形を掘って、ブロックを置いて、クラフトして、昼夜のある世界を冒険する。
Three.js（`three` パッケージ）+ Vanilla JS。画像・音声ファイルは使わず、テクスチャもサウンドもすべてプログラムで生成している。

## 概要

- 1人用。クリエイティブ（ブロック無限・飛行可）とサバイバル（採集・クラフト・体力・夜はゾンビ）の 2 モード
- ワールドは 3 スロットに自動セーブ（localStorage）。シード指定で同じ地形を再現できる
- PC（キーボード＋マウス）/ スマホ・タブレット（仮想スティック＋タッチ）に対応

| ジャンプ | スペース（クリエイティブで 2 回押し: 飛行 ON/OFF、`F` でも可） |
| しゃがむ / 飛行中に下降 | Shift |

| ブロックをコピー（クリエイティブ） | ホイールクリック |
| もちもの / クラフト | E |
| メニュー | Esc |

### タッチ

| 操作 | 方法 |
| --- | --- |
| 移動 | 画面左側をタッチしてスティック（大きく倒すとダッシュ） |
| 見まわす | 画面右側をドラッグ |
| 置く / 作業台を開く | タップ（十字の先のブロックのとなりに置く）または 🧱 ボタン |

## ゲームルール

### クリエイティブ
- すべてのブロックを無限に使える。壊しても何も手に入らない
- 空を飛べる。ダメージを受けない。ゾンビは出ない

### サバイバル
- ブロックを壊すとドロップ（石→丸石、草→土、葉→たまに りんご、石炭鉱石→石炭）が「もちもの」に入る（最大 64 個/スタック、ホットバー 9 + 27 枠）
- 体力 10 ハート（20HP）。落下（3 ブロック超）・溺れ・ゾンビの攻撃でダメージ。時間でゆっくり回復。りんごで +2 ハート
- やられても「もちもの」はそのまま。初期地点でリスポーン
- 夜（暗い場所）にゾンビが出現してプレイヤーを追いかける。3 回なぐると倒せる。朝日で燃える
- ヒツジをなぐると羊毛がとれる（しばらくすると生えてくる）
- 壊す速さはブロックごとに違う（土 0.7 秒、石 2.2 秒、鉱石 3 秒…）。岩盤は壊せない

### クラフト（順不同レシピ。🎒 のクラフトタブからいつでも可。作業台を使っても開く）
原木→木材、木材→棒、棒+石炭→たいまつ、砂+石炭→ガラス、丸石+石炭→石、石→石レンガ、土+石炭→レンガ、羊毛+花→色つき羊毛 など。`blocks.js` の `RECIPES` を参照。

### 昼夜
1 日は 12 分（`DAY_LENGTH = 720` 秒）。空の色・太陽/月・星・雲・ワールドの明るさが変化する。設定で「いつも昼」にできる。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `styles.css` | 画面・HUD・オーバーレイ・タッチ UI |
| `game.js` | ゲーム本体。状態遷移（title / loading / playing / paused / dead）、チャンク読み込みのスケジューリング、操作（壊す・置く・なぐる）、HUD、セーブ |
| `world.js` | チャンク管理、`getBlock/setBlock`、編集の記録、ライト+メッシュ用リージョンの組み立て |
| `worldgen.js` | 地形生成（高さマップ・バイオーム・洞窟・鉱石・木・花・雪） |
| `lighting.js` | 空の光 / ブロックの光（0〜15）の BFS 伝播 |
| `mesher.js` | チャンクのメッシュ化（面カリング、頂点 AO、スムースライティング、cross / torch / liquid / layer 形状） |
| `renderer.js` | Three.js。チャンク用シェーダー、空・太陽・月・星・雲、選択枠、ひび割れ、パーティクル、手に持つブロック |
| `textures.js` | 16×16 ドット絵テクスチャを生成してアトラス化 |
| `blocks.js` | ブロック/アイテム定義、クリエイティブのパレット、レシピ、アイコン生成 |
| `physics.js` | AABB とボクセルの当たり判定、レイキャスト（DDA） |
| `player.js` | 移動・ジャンプ・水泳・飛行・落下ダメージ・息・回復 |
| `mobs.js` | ブタ / ヒツジ / ニワトリ / ゾンビ（箱モデル + 簡易 AI） |
| `inventory.js` | インベントリとクラフトの UI |
| `input.js` | キーボード / マウス（ポインターロック）/ タッチ（スティック・ドラッグ・ボタン） |
| `audio.js` | WebAudio で効果音と環境音楽を合成 |
| `save.js` | localStorage の読み書き |
| `noise.js` | シンプレックスノイズ、ハッシュ、乱数 |

## 状態 / データ

- **ワールド**: 高さ 96、チャンク 16×16×96（`Uint8Array`、`idx = (x*16 + z)*96 + y`）。海面 y=32
- **ライティング**: チャンクの周囲 12 ブロック（`PAD`）を含むリージョンで計算し、頂点ごとに `aLight = (sky, block, shade*AO)` として焼き込む。昼夜はシェーダーの `uDaylight` で乗算
- **描画距離**: 設定で 3〜8 チャンク（自動: PC 6 / タッチ 4）。読み込みは毎フレームの時間予算（PC 12ms / タッチ 9ms）内で近い順に生成→メッシュ化。遠いチャンクは破棄して再生成する
- **保存データ**（`localStorage['block-world:v1']`）: 設定 + 3 スロット。各スロットは `{name, seed, mode, time, player{x,y,z,yaw,pitch,health,flying}, spawn, inventory{hotbar,main,selected}, edits{"cx,cz":[idx,id,...]}, playTime}`。地形はシードから再生成し、変更したブロックだけを保存する
- 自動セーブ: 25 秒ごと、ポーズ時、タブが隠れたとき、ページを閉じるとき

## 画面 / レスポンシブ

- `100svh` ベース、セーフエリア対応（`env(safe-area-inset-*)`）
- 回転・リサイズでキャンバスとカメラを再計算
- タッチ端末（`pointer: coarse`）では仮想スティックとボタンを表示、PC ではポインターロック
- 水中はフォグが短くなり青いオーバーレイ、ダメージ時は赤いオーバーレイ

## 素材 / クレジット

- 外部素材なし。テクスチャ（`textures.js`）、モブ（`mobs.js`）、音（`audio.js`）はすべてコードで生成
- フォント: Google Fonts（Outfit / M PLUS Rounded 1c）

## TODO / 既知の課題

- 水は流れない（置いた水はその場にとどまる）。砂・砂利も落ちない
- アイテムをワールドに落とす（ドロップエンティティ）は無く、拾ったものは直接「もちもの」に入る
- ライティングはチャンク境界から 12 ブロック以上離れた光源の影響は切れるため、ごくまれに洞窟のチャンク境界で明るさの段差が出る
- メッシュ生成はメインスレッド（時間予算で分割）。古い端末では描画距離を「ちかい」にすると快適
- ベッド（リスポーン地点の変更）、道具（ツルハシなど）、動物の繁殖は未実装
