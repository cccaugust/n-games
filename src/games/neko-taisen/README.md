# ねこぐんだん大戦争（neko-taisen）

「にゃんこ大戦争」風の横スクロール拠点攻防タワーディフェンス。お金をためて ねこを出撃させ、左にある てきの城を破壊すれば勝ち。右の ねこ城が壊されたら負け。
Vanilla JS + Canvas 2D。画像・音声ファイルは使わず、キャラクター・背景・効果音・BGM はすべてプログラムで生成している。

## 概要

- 1人用。12ステージ（ボスステージ 4つ）
- 12種類の ねこユニット（ステージクリアで解放）、12種類の敵（ボス 4体）
- ユニット・お城の XP レベルアップ、デッキ編成（最大10体）、★評価、自動セーブ

## ゲームルール

### バトル
- お金（¥）は時間で増える。はたらきねこ Lv1〜8 で増加速度と上限が上がる（`workerStats`）
- ユニットは出撃後、前方に進み、射程内に敵（または城）が入ると止まって攻撃する
  - 単体攻撃: 射程内で最も近い標的 / 範囲攻撃: 射程内すべて
  - 攻撃は `foreswing` 秒後にヒット、`atkInterval` 秒ごとに繰り返す
- ノックバック: HP が `maxHp / kb` 減るごとに後方へ押し戻される。ナイトねこ・ゴリドン等は確率で強制ふっとばし
- 特殊: クリティカル（ニンジャ、3倍）、鈍足（まほうねこ、速度半減・攻撃間隔1.4倍）
- ボスは敵城の HP が条件以下になると登場。登場時の衝撃波で全ねこがノックバックする
- ねこキャノン: 敵全体にダメージ＋ノックバック。お城レベルで威力・充電時間が変わる
- 敵を倒すとお金が入る（敵ごとの `money`）
- 勝利: 敵城 HP 0 / 敗北: ねこ城 HP 0

### 評価・報酬
- ★1 クリア / ★2 ねこ城 HP 50%以上 / ★3 ねこ城ノーダメージ
- 初回クリアで `stage.xp`、再クリアで 1/3、★が増えると +1/5 ボーナス。負けても 1/10
- ステージクリアで次のステージとユニットが解放（`unit.unlock` = クリアが必要なステージ番号）

### 強化
- ユニット Lv1〜20: HP・攻撃 ×(1 + 0.15×(Lv−1))。費用 `unitLevelCost(lv)`
- ねこ城 Lv1〜10: 城HP 5000+1500/Lv、キャノン 400+150/Lv、充電時間短縮。費用 `castleLevelCost(lv)`

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面構成（タイトル / ステージ選択 / 強化・編成 / バトル / あそびかた） |
| `style.css` | デザイントークン・コンポーネント・レスポンシブ |
| `game.js` | エントリ。画面遷移・入力・ゲームループ・HUD・結果処理 |
| `battle.js` | バトルシミュレーション（DOM 非依存。Node でも実行可） |
| `render.js` | Canvas 描画（カメラ・背景・ユニット・パーティクル・ミニマップ）、カードアイコン生成 |
| `sprites.js` | 全キャラ・城・背景飾りのプロシージャル描画 |
| `audio.js` | WebAudio 効果音・簡易シーケンサー BGM（menu / battle / boss） |
| `save.js` | localStorage セーブ、解放判定、レベルアップ、結果記録 |
| `data.js` | ユニット / 敵 / ステージ / テーマ / 計算式 |

## 状態 / データ

- `Battle`: `money`, `workerLevel`, `cannon{charge}`, `cats[]`, `enemies[]`, `playerBase`, `enemyBase`, `slots[]`（デッキ＋クールダウン）, `result`
- `Entity`: `x`, `hp`, `state`(walk/attack/kb/dead), `t`, `kbTaken`, `slowT`, `lane`（描画の奥行き）
- イベント配列 `battle.events` を `game.js` が毎フレーム消費して効果音・演出に変換する
- セーブ（`localStorage` キー `neko-taisen-save-v1`）: `xp`, `castleLevel`, `unitLevels`, `deck`, `stages{id:{stars,bestTime,plays}}`, `settings{sfx,bgm,speed}`, `stats`
- タイトル画面の「データをリセット」で全消去

## 画面 / レスポンシブ

- PC / タブレット / スマホ対応。縦向きでも横 640 ワールド px 以上が見えるようスケールを決める（`Renderer.resize`）
- `100dvh`・セーフエリア（`env(safe-area-inset-*)`）対応、キャンバスは `touch-action: none`
- 横向き低高さ（〜480px）ではカードを 10 列・小型化
- `devicePixelRatio` 対応（最大3）。ダメージフラッシュはオフスクリーン Canvas で合成
- 画面非表示時は自動ポーズ

## バランス調整

`battle.js` は DOM に依存しないので、Node から簡易 AI で全ステージを自動プレイして難易度を確認できる（開発時はスクラッチの `sim.mjs` を使用）。
敵の強さは `stage.mag`、出現は `spawns` / `triggers` で調整する。
