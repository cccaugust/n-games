# ワードモンスターズ

英語でこたえてドット絵モンスターを集める、収集型の英単語クイズ。小学生〜中学1年でよく使う基礎単語（約120語／12カテゴリ）を、4つの出題形式で楽しく学べる。

## 概要

- クイズに正解すると、その単語にちなんだ「ドット絵モンスター」をゲット → 図鑑に登録。
- 同じ単語に何度も正解すると「マスタリー（★）」が上がり、★3で **色ちがい（シャイニー）** が解放。
- レア度（コモン/レア/スーパーレア/ウルトラレア）ごとにホログラム枠で見た目が豪華に。

## 操作方法

- **PC**: マウス/キーボードのクリックで選択肢を選ぶ。
- **タッチ**: 選択肢をタップ。`🔊` ボタンで発音をもう一度再生。
- 図鑑のカードをタップすると詳細（例文・発音・色ちがい）が見られる。

## ゲームルール

- 1セッション 10問。未ゲット・苦手な単語が優先して出る（学習効率＆収集が進む）。
- 出題形式は4種類をランダム：
  - **いみは？**（英→日）
  - **えいごで なんていう？**（日→英）
  - **🔊 きこえたのは？**（リスニング → 意味）
  - **ただしいスペルは？**（似たつづりから正解を選ぶ）
- 正解でスコア＋連続ボーナス、経験値（XP）獲得。XP 200ごとにレベルアップ。
- モンスターは出題中はシルエット、正解すると色つきで登場する。

## 構成（主要ファイル）

- `index.html` … 画面の骨組み（ホーム/カテゴリ/クイズ/リザルト/図鑑/オーバーレイ）
- `style.css` … デザイントークン・ホログラム・アニメ・レスポンシブ
- `game.js` … メインロジック（セーブ・出題・採点・図鑑・演出）
- `monster.js` … ドット絵モンスター自動生成エンジン（単語をシードに決定論生成）
- `audio.js` … 効果音（Web Audio）と英語読み上げ（Web Speech API）
- `data/words.js` … 単語データ（英・日・カテゴリ・例文・レア度・体型）

## 状態／データ

- セーブは `localStorage`（キー: `wm-save-v2`）。図鑑の捕獲状況・正解数・XP・設定を保存。
- DB不要。端末ごとにブラウザ内へ保存される。
- モンスターは外部画像を使わず、コードで毎回生成（素材ファイル不要）。

## モンスター生成について

`monster.js` が単語名をシードに、11種の体型（slime/fluff/beast/bird/fish/snake/dragon/ghost/golem/plant/robot）× 色 × レア度で左右対称のドット絵を生成。
同じ単語は常に同じ姿になるので、図鑑として安定する。新しい単語を `data/words.js` に足すだけでモンスターが増える。

## 画面／レスポンシブ

- PC/タブレット/スマホ対応。`100svh`・セーフエリア・`viewport-fit=cover` 対応。
- タップ領域は最低48px。`prefers-reduced-motion` でアニメ控えめ。
- canvas は `devicePixelRatio` を考慮し、`image-rendering: pixelated` でくっきり表示。

## 素材／クレジット

- 画像・音の外部素材なし（すべてコード生成）。
- フォント: Google Fonts（Baloo 2 / Fredoka）。
- 発音は端末の Web Speech API を使用（対応していない端末では読み上げ系の出題を自動でスキップ）。
