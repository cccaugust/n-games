# クアルト！（Quarto）

2人用の名作アブストラクトボードゲーム。1台のタブレット/スマホで対面プレイ、またはCPUと対戦できます。

## 概要

16個のコマには「色（明・暗）」「高さ（高・低）」「形（丸・四角）」「穴（あり・なし）」の4つの違いがあります。プレイヤーは **自分のコマを選べず、相手に渡す** のがコア。たて・よこ・ななめの4マスで「共通する特徴が1つでも揃った」列を作った人の勝ちです。

## 操作方法

- **タイトル画面**: 「ふたりで あそぶ」または「CPUと あそぶ」（やさしい / ふつう / つよい）を選ぶ
- **コマを渡す番**: 下の「のこっているコマ」から1つタップ → 相手に渡る
- **コマを置く番**: 盤面の空きマスをタップ → 渡されたコマが置かれる
- **もどす**: 手番トレイの「↶ もどす」で1手戻す（CPU戦では自分の直前の判断まで戻る）
- **ヘッダー**: 「？」あそびかた / 🔊 サウンドON・OFF / ☰ メニュー（やりなおす・設定・タイトルへ）
- **キーボード**: Esc でメニュー開閉

## ゲームルール

1. 先手が、相手に渡すコマを1つ選ぶ
2. 相手はもらったコマを盤面の好きなマスに置く
3. 続けてそのプレイヤーが、相手に渡すコマを選ぶ
4. 以後、交互に「相手に渡す→受け取って置く」を繰り返す
5. 4つ並んだ列に「全員が共通する特徴」が1つでも揃ったら、置いた人の勝ち（自動判定）
6. 全16コマを置き切っても揃わなければ引き分け
7. 次のラウンドは負けた人が先手（引き分けなら前回と逆）

### CPUの強さ

| レベル | 置き方 | 渡し方 |
|---|---|---|
| やさしい | 勝てるマスを 65% の確率で取る。それ以外はランダム | 45% はランダム、残りは安全なコマ |
| ふつう | 勝てるマスは必ず取る。置いた後に「安全に渡せるコマ」が最も多く残る所へ | 相手が即勝ちできないコマからランダム |
| つよい | ふつうに加え、渡した後の相手の余裕（相手が安全に渡せる数）が最小になる手を1手先読み | 同上。安全なコマが無い場合は勝ちマスが最少のコマ |

### おたすけ表示（設定でON/OFF）

- 渡す番: 相手が即座に勝てるコマに「!」バッジ
- 置く番: 置くと勝てるマスに「★」バッジ

## 構成

- `index.html`: マークアップ。共有SVG定義（木目グラデ）、タイトル / メニュー / 設定 / ルール / リザルトの各オーバーレイ
- `style.css`: デザイントークン、レイアウト、コンポーネント、レスポンシブ
- `game.js`: 状態管理、勝利判定、CPU、レンダリング、効果音、保存
- `README.md`: このファイル

## 状態 / データ

- `state.mode`: `'pvp'` / `'cpu'`
- `state.cpuLevel`: `'easy'` / `'normal'` / `'hard'`
- `state.board`: 16マスの配置（コマ番号 0〜15 or null）
- `state.available`: 残コマのSet
- `state.selectedPiece`: 渡されたコマ
- `state.phase`: `'select'` / `'place'` / `'over'`
- `state.currentPlayer`: 手番（1 or 2。CPU戦ではCPU=2）
- `state.winner`: `1` / `2` / `'draw'` / `null`
- `state.winLine` / `state.winInfo`: 勝利ラインと揃った属性ビット
- `state.history`: アンドゥ用スナップショット（PvPは毎手、CPU戦は人間の操作前のみ保存）
- `state.scores`: 今回のセッションの勝ち数（タイトルに戻るとリセット）

### 永続化（localStorage）

- `quarto.settings.v2`: `{ sound, hints, face, haptics, cpuLevel }`
- `quarto.records.v2`: 通算成績 `{ pvp: {p1,p2,draw}, cpu: { easy|normal|hard: {win,lose,draw} } }`（設定画面からリセット可）

## コマのエンコード（4ビット）

| ビット | 1 | 0 |
|---|---|---|
| bit0 | 高い | 低い |
| bit1 | 暗い | 明るい |
| bit2 | 四角 | 丸 |
| bit3 | 穴あり | 穴なし |

勝利判定は4コマのANDとORで共通ビットを抽出。`winningCells()` はマスを通る列だけを見る高速版を使用。

## コマの描画

コマは `pieceSVG()` が生成するインラインSVG。上面（グラデ+木目パターン+リム+ハイライト）と側面（高さぶんの帯）を重ねて疑似3Dにしており、「高い」コマは側面が長く描かれるので高さの違いが一目で分かる。グラデ/パターン定義は `index.html` 冒頭の共有 `<svg><defs>` にまとめている。

## 画面 / レスポンシブ

- **スマホ縦（〜480px）**: P2 / 盤 / 手番トレイ / ラック(8×2) / P1 を縦積み。盤サイズは `100svh` から他UI分を引いて縦に収まるよう計算
- **タブレット縦（720px〜）**: 同構成で余白広め。ラックは最大560pxに制限
- **横向き（700px〜）**: P2左 / 盤中央 / P1右 / ラック(16×1)下。パネルは縦カード型
- **スマホ横（高さ520px以下）**: 左にP1/P2、中央に盤、右にラック(4×4)、下に手番トレイ
- **対面モード**: ふたりで遊ぶ縦画面のとき、P2パネル・手番トレイ・ターン通知を180°回転（設定でOFF可）
- セーフエリア対応（`env(safe-area-inset-*)`）、`prefers-reduced-motion` でアニメーション抑制

## 演出

- ターン切替トースト、コマ受け渡しのポップ、置いた時の落下アニメ、直前の手のリング
- 勝利時: 勝利ライン描画 → 「QUARTO!」スタンプ → 紙吹雪 → リザルト（揃った4コマと理由を表示）
- 効果音はWebAudio合成（外部ファイル不要）。`navigator.vibrate` 対応端末では置いた時に振動
