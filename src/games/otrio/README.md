# OTRIO

3x3の盤に「小・中・大」の輪を置いてそろえる、最大4人対戦のボードゲームです。タブレット/スマホ/PCで遊びやすいよう大きめのタップUIにしています。

## 操作
- スタート画面で人数（2〜4人）を選び、**順番ごとに色をえらんで**「はじめる」
  - 「1番目」「2番目」…の行で好きな色をタップ。他の人が使っている色をタップするとその人と色を**交換**（色の重複なし）
- 画面下のサイズボタン（小/中/大）を選ぶ → 盤面のマスをタップで配置
- マスをホバー（PC）すると半透明の **ゴーストリング** で置いた結果がプレビューされます
- 右上の 🔊 ボタンで効果音 ON/OFF
- 「リセット」で同じ人数のまま再開、「新しい対戦」で人数選び直し

## 結果画面
勝負がつくと結果画面が開きます。
- **ふりかえり**: ミニ盤面で1手ずつ巻き戻して見られる（◀ ▶ ボタン / スライダー）。最後の手では勝ちにつながった輪を光らせる
- **今回の記録**: 各プレイヤーが置いた輪の数・残りの数（勝者に 👑）
- **通算成績**: 同じ人数で続けて遊んだ試合の勝ち数・引き分け数（「はじめる」で人数を選び直すと 0 に戻る）
- 「盤面を見る」で閉じて実際の盤面を確認でき、ステータスバーの「📋 結果を見る」でまた開ける

## プレイヤー
- 最大4人まで参加可
- 順番（1番目〜4番目）は固定、色は順番ごとにスタート画面で選べる
- 選べる色（アイコンは色に連動）: 青 🐬 / ピンク 🌸 / 緑 🌿 / 黄 ⭐ / オレンジ 🍊 / 紫 🍇
- 初期値: 1番目 青 / 2番目 ピンク / 3番目 緑 / 4番目 黄
- 各プレイヤーは小×3 / 中×3 / 大×3 を持ちスタート

## 勝利条件
- 同じサイズの輪を縦・横・斜めで3つそろえる
- 同じマスに 小・中・大 を全部自分のリングでそろえる（入れ子）
- 直線上で「小→中→大」または「大→中→小」とサイズ階段で並べる

置けないプレイヤー（在庫切れ・置き場なし）の番は自動でスキップされます。誰も置けなくなったら引き分け。

## エフェクト・サウンド
- リング配置時にプレイヤーカラーのパーティクル＆リングパルス
- 勝利時に紙吹雪 + 勝利アルペジオ
- 効果音は **Web Audio API** で生成（音声ファイル不要）

## 構成
- `index.html`: UI（セットアップオーバーレイ、プレイヤーチップ、盤面、ピッカー、結果画面）
- `game.js`: 状態管理、ルール、勝敗判定、サウンド（SFX）、パーティクル、紙吹雪

## 状態 / データ
- ローカル状態のみ（永続化なし）
- 主要オブジェクト: `state.numPlayers`、`state.board`（9マス × {s,m,l}）、`state.stock`、`state.current`、`state.selectedSize`
- `state.colors`: 順番ごとの色ID配列（`PALETTE` の id）。`colorOf(p)` / `iconOf(p)` で参照し、`applyPlayerColors()` で CSS変数 `--p1`〜`--p4` に反映
- `state.moves`: 置いた手の記録 `{ player, idx, size }[]`（ふりかえり用）
- `state.winInfo.rings`: 勝ちにつながった輪 `{ idx, size }[]`
- `state.tally`: 通算成績 `{ games, draws, wins }`（メモリのみ。ページを閉じると消える）

## レスポンシブ
- `viewport-fit=cover` と safe-area inset 対応
- 盤面は `min(82vmin, 560px)` でタブレット最適化、`100svh` 想定
- ボタンは最小44px以上、タッチ向けに大きめ
- プレイヤーチップは `auto-fit, minmax(140px, 1fr)` で自動折返し
- 結果画面は画面に収まらないとき（スマホ横向きなど）縦スクロールできる

## 既知の課題
- AI（CPU相手）モード未実装。現状はローカル多人数対戦のみ
